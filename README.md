# Welcome to Code Break
Thank you for taking your time to go through this repo.
This was an event conducted in a college symposium.
Please follow the steps below to set up your system for the game.

*Step 1:* Ensure you have installed the following applications (This may give you a clue as to what the puzzles are made of!).
>1. Install python and the `tkinter` library after python installation.
>1. Any DataBase browzer (I've used DB Browzer for SQLite)
>1. Sonic Visualizer (or any other application which does similar functions)
>1. Set the image in the file as your lock screen image! (please don't open the image for the integrity of the game!)

*Step 2:* Run the **Code Break** program.\
*Step 3:* Enjoy the game!


## Note to self:
1. ***Do not*** close the program while you are in the middle of a run
2. You can create a leader board in the issues section with your score, your name and the scenario you played in the issues section but please mention "SCORE:" at the top of the post before posting it.
3. You can have your friends play this game and post their scores too. 
4. Feel free to play all the scenarios, although you would know what to do at this point as they are very similar in structure.
5. Have fun and enjoy the game!
